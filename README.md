```mermaid
%%{init: {'theme': 'base', 'themeVariables': {'primaryColor': '#1a1a1a', 'primaryTextColor': '#ffffff', 'primaryBorderColor': '#DC2626', 'lineColor': '#EF4444', 'actorBkg': '#1a1a1a', 'actorBorder': '#DC2626', 'actorTextColor': '#ffffff', 'signalColor': '#EF4444', 'signalTextColor': '#ffffff', 'noteBkgColor': '#7f1d1d', 'noteTextColor': '#ffffff'}}}%%
sequenceDiagram
    autonumber
    participant C as Client
    participant A as Express API
    participant D as PostgreSQL

    C->>A: POST /api/auth/login
    A->>D: Verify credentials
    alt 2FA disabled
        A-->>C: Set httpOnly cookies (access + refresh)
    else 2FA enabled
        A-->>C: requiresOtp true (OTP sent by email)
        C->>A: POST /api/auth/verify-otp
        A-->>C: Set httpOnly cookies (access + refresh)
    end
    Note over C,A: Later requests carry the accessToken cookie automatically
    C->>A: POST /api/auth/refresh (when the access token expires)
    A-->>C: New accessToken cookie
```
