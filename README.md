<table width="100%" border="0" align="center">
<tr>
<td align="center" style="padding: 22px;">
  <h3>🔐 RoleGuard</h3>
  <p><i>A role-based access control and workspace collaboration platform built during my internship at Richinnovations. It covers authentication, workspaces and teams, background jobs, real-time presence, payments, and admin monitoring.</i></p>
  <br />
  <p>
    <a href="TODO_ROLEGUARD_URL"><img src="https://img.shields.io/badge/Live%20Demo-🚀%20Visit-DC2626?style=for-the-badge&logo=vercel&logoColor=white&labelColor=0a0a0a" alt="Live Demo" /></a>
    &nbsp;&nbsp;
    <a href="TODO_ROLEGUARD_REPO"><img src="https://img.shields.io/badge/Source%20Code-💻%20View-111111?style=for-the-badge&logo=github&logoColor=EF4444&labelColor=0a0a0a" alt="Source Code" /></a>
  </p>
</td>
</tr>
</table>

**What's in it**

- 🔑 **Auth &amp; access control**: JWT access and refresh tokens in httpOnly cookies, optional email-OTP two-factor auth, bcrypt hashing, Zod validation, rate limiting, OAuth login (Google, GitHub, Microsoft)
- 🛡️ **RBAC**: platform roles (Admin / User) plus per-workspace roles (Owner / Admin / Member), enforced by middleware and in the service layer
- 👥 **Workspaces &amp; teams**: email invitations with accept/decline, role changes, ownership transfer, leave and delete flows
- ⚙️ **Background jobs**: BullMQ on Redis for email, SMS and notification jobs, with exponential-backoff retries, hold/release, pause/resume, and an admin queue monitor
- 🔔 **Real-time &amp; notifications**: Socket.IO presence and typing indicators, in-app notification center, per-category preferences, mute windows, web push, admin announcements
- 📊 **Analytics**: admin dashboard with CSV, JSON and PDF export
- 🔌 **Integrations**: Razorpay payments with signature and webhook verification, Twilio SMS, Nodemailer email, Cloudflare R2 avatar storage
- 🚢 **Operations**: Docker images, Docker Compose, Nginx, Winston logging, liveness and readiness health checks, PostgreSQL backup script
